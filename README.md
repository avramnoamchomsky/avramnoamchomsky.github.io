My personal website focused on Linux, embedded systems, and low-level software.

This site is a place for me to share my interests, projects, and things I'm learning.

I'm particularly interested in:

## Built With

The site is built from scratch using:

- HTML
- CSS
- JavaScript
- GitHub Pages

No frontend framework is currently used.

- Animated navigation transitions
- Reduced-motion support
